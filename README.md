# School Timetable 2027

Монголын ерөнхий боловсролын сургуульд зориулсан хичээлийн хуваарь зохиох программ:
2–3 ээлж, олон байр, дэд бүлэг, хос цаг, А/Б 7 хоног, хамтатгасан анги, хамтран заах багш.

## Ажиллуулах

```bash
npm install
npm run dev        # http://localhost:3000
```

Хөгжүүлэлтийн сервер (`npm run dev` / `npm run preview`) дээр автомат хуулбар `backups/` хавтаст хадгалагдана.
Статик байршуулалт эсвэл PWA үед хуулбар хөтчийн дотор (IndexedDB, сүүлийн 30) хадгалагдана.

## Хуваарь бодогч

`src/utils/solver.ts` — хүндийг нь эхэлж байршуулж, гацвал саад болж буй хичээлийг гаргаж засаад,
дараа нь зөөх/солих замаар цонх, тархалт зэрэг зөөлөн торгуулийг бууруулна. Web Worker дотор ажиллана.

- Хатуу хязгаарлалт (`src/utils/constraints.ts`): багш, анги, танхимын давхардал (бодит хонхны цагаар),
  дэд бүлгийн хуваалт, А/Б, хуваалцах танхимын багтаамж, ээлж бүрийн чөлөөт цаг.
- Дүрмийн жин: Хатуу 1000, Өндөр 50, Энгийн 10.
- Гараар засах (`src/utils/manualEdit.ts`): чирэхэд боломжтой нүд ногоон, солих боломжтой шар, боломжгүй улаан.
  Буцаах/дахих: Ctrl+Z / Ctrl+Y.

## Орлон заалт

"Орлон заалт" цонхонд огноо сонгоод өвчтэй, чөлөөтэй багшийг (бүтэн өдөр эсвэл зарим цаг) нэмнэ.
`src/utils/substitution.ts` тухайн өдрийн хичээлүүдийг нь олж, шийдлийг жигнэж эрэмбэлнэ:
хамтран заагчгүй орох, ангийн өөр цагтай солих (багш өөрөө заана), дэд бүлэг нийлүүлэх,
ижил хичээлийн сул багш, ангийн өдрийн өмнө/ард шилжүүлэх, анги эрт тарах/хожуу ирэх,
сүүлийн хичээлийг татах, зэрэгцээ 2 анги нийлүүлэх, өөр хичээлийн багш хянах, хичээл орохгүй.
Менежер санал болгосныг сольж болно (гараар сонгосон нь "Автоматаар" дарахад хадгалагдана).
Суурь хуваарь өөрчлөгдөхгүй; өдөр бүрийн төлөвлөгөө тусдаа хадгалагдана. Хэвлэх, багш нарт мэдэгдэл хуулах,
хугацааны тайланг Excel-ээр татах боломжтой.

## Тест

```bash
npm test           # хатуу хязгаарлалт, гараар засах, Excel нэгтгэл (≈30 сек)
npm run stress     # 120 бүлэг, 3 ээлж, 3 байртай стресс тест (STRESS_SECONDS=60)
```

## Windows программ ба лиценз

Программ Windows 10/11 (64 бит)-д **суулгагчаар** суулгагдаж, анх нээхэд **лицензээр идэвхжинэ**.
Electron дээр ажилладаг; суулгагч нь NSIS (Inno Setup биш), Linux/macOS/Windows аль дээр ч бүтээгдэнэ (wine шаардлагагүй).

```bash
npm run dist:win   # → release/SchoolTimetable2027-Setup-<хувилбар>.exe
```

Суулгагч: Монгол хэлтэй, лицензийн гэрээ, хавтас сонгох, Start цэс/ширээний товчлол, «Programs and Features»-д бүртгэгдэнэ,
шинэчлэхэд өгөгдөл хадгалагдана. Устгахад хуваарь/лицензийг устгах эсэхийг асууна (анхдагч — үлдээнэ);
`Documents\School Timetable 2027\backups` дахь хуулбарууд хэзээ ч устахгүй.

### Лицензийн ажлын урсгал

1. **Нэг удаа** (зөвхөн борлуулагчийн компьютер дээр): `npm run license:keygen` — `license-keys/private.pem` (нууц, git-д орохгүй)
   ба `electron/license-public.pem` үүснэ. Түлхүүр солигдвол программыг дахин бүтээнэ.
2. Сургууль программаа суулгаж нээхэд **машины код** (`XXXX-XXXX-XXXX-XXXX`) харагдана — түүнийг илгээнэ.
3. Лиценз олгох:
   ```bash
   npm run license:issue -- --machine ABCD-EFGH-JKLM-NPQR --licensee "12-р сургууль" --expires 2027-08-31
   ```
   Гарсан `STT1.…` түлхүүрийг сургуульд өгнө (эсвэл `--out school12.lic` файлаар). Бүх олголт `license-keys/issued.csv`-д бүртгэгдэнэ.
4. Сургууль түлхүүрээ буулгаж (эсвэл .lic файлаа нээж) идэвхжүүлнэ.

Лиценз Ed25519 гарын үсэгтэй, тухайн компьютерт (Windows MachineGuid) уягдсан, хугацаатай. Засварласан, өөр компьютерынх,
хугацаа дууссан эсвэл цаг ухраасан тохиолдолд идэвхжүүлэх цонх гарч, өгөгдлөө файлаар хадгалах боломж үлдэнэ.
Хугацаа дуусахаас 30 хоногийн өмнө толгойд анхааруулга гарна.

**Кодын гарын үсэг:** гарын үсэггүй суулгагчид Windows SmartScreen «Windows protected your PC» гэж анхааруулна
(«More info → Run anyway»). Худалдаанд гаргахдаа code-signing гэрчилгээгээр (`signtool sign`) суулгагч болон
`SchoolTimetable2027.exe`-д гарын үсэг зурна.

Тест: `npm run build:desktop && xvfb-run -a node tests/desktop.e2e.cjs`

### Хөнгөн хувилбар (Electron-гүй, ~2 MB суулгагч)

```bash
npm run dist:win:lite   # → release/SchoolTimetable2027-Lite-Setup-<хувилбар>.exe
```

| | Бүрэн (Electron) | Хөнгөн (Go + WebView2) |
|---|---|---|
| Суулгагч | ~107 MB | **~2 MB** |
| Суусны дараа | ~300 MB | ~6 MB |
| Хөдөлгүүр | Chromium программд багтсан | Windows 10/11-ийн Microsoft Edge WebView2 |

- `desktop-lite/` — Go программ: цонх (WebView2), `window.desktop` гүүр (`bridge.js`), лиценз (`license.go`), нөөц хуулбар.
  Сангууд `desktop-lite/vendor`-д багтсан тул интернэтгүй бүтээгдэнэ (Go 1.22+ шаардлагатай).
- **Лиценз бүрэн хувилбартай яг ижил**: ижил түлхүүрийн хэлбэр, машины код, `npm run license:issue`, ижил `license.lic` файл —
  өмнө олгосон лицензүүд хэвээр ажиллана, хоёр хувилбарын хооронд шилжихэд дахин идэвхжүүлэх шаардлагагүй.
- Хуваарийн өгөгдөл: `%LOCALAPPDATA%\School Timetable 2027\WebView2` (бүрэн хувилбараас тусдаа — шилжихдээ «Хадгалах»-аар файлд
  гаргаад «Нээх»-ээр оруулна; нөөц хуулбарууд `Documents` дотор хоёуланд нь харагдана).
- WebView2 Windows 11-д суусан, Windows 10-д Edge-ийн шинэчлэлээр ихэвчлэн суусан байдаг. Байхгүй бол суулгагч болон программ
  Microsoft-ийн албан ёсны татах хуудсыг санал болгоно.
- Суулгагч өмнөх хувилбарыг (бүрэн эсвэл хөнгөн) өөрөө солино; лиценз хадгалагдана.

Тест: `npm run test:lite` (Go ↔ Node лицензийн нийцэл) ба `npm run build:desktop && node tools/build-lite.mjs && node tests/lite.e2e.cjs`
